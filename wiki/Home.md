## ⚡ Core Philosophy: The Zero-Bloat Mandate

AI agents suffer from **context degradation**: as conversations exceed 20,000 tokens, response latency spikes ($TTFT > 10s$), reasoning errors climb by $40\%$, and monthly LLM API bills explode.

UAP solves this through an autonomous 4-stage pipeline:
1. **Virtual `@` Pinpointing:** Turn-1 resolution of target files using `PROJECT_STATE.md`.
2. **Context Economy:** Selective extraction of targeted function symbols.
3. **Single-Pass Rigor:** Batched contiguous edits before running test suites.
4. **Living Memory Auto-Sync:** Automated state tracking via `uap record`.
