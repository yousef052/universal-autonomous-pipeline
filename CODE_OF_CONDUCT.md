# Community Code of Conduct

## Our Commitment

We are dedicated to providing a respectful, welcoming, and harassment-free environment for everyone participating in this project, regardless of background, experience level, or identity.

---

## Standards of Collaboration

### Expected Behavior
- **Professionalism & Empathy:** Treat fellow contributors and maintainers with kindness, patience, and constructive feedback.
- **Technical Rigor:** Focus technical discussions on architecture, benchmarks, code safety, and evidence-backed engineering.
- **Constructive Code Reviews:** Critique code solutions constructively rather than personal competence.
- **Respect for Privacy:** Respect boundaries and refrain from publishing private contact details or personal data.

### Unacceptable Behavior
- Trolling, insulting, or derogatory comments.
- Harassment in any form, public or private.
- Malicious submissions, backdoors, or attempts to circumvent repository security guardrails.

---

## Enforcement & Reporting

Project maintainers are responsible for clarifying and enforcing our standards of acceptable behavior.

If you encounter or observe unacceptable behavior, please report the issue directly via:
- **GitHub Private Repository Advisory or Maintainer Mention:** Open a confidential report through GitHub repository channels or tag the repository maintainer (`@yousef052`).

All reports will be reviewed promptly, treated with strict confidentiality, and investigated fairly.
